# Function Bookmarks

The developer marks important functions and lines with the Function Bookmarks extension. Each bookmark can have a display name, tags, a number (1-9, used as the order of a walkthrough) and a Markdown note. Bookmarks follow the code when files change, so their positions are reliable.

Run the CLI from the project root:

```
{{CLI}} <command>
```

It needs Node.js. Line numbers start at 1, like the editor. A `<ref>` is a number 1-9, a bookmark id, `<file>#<Function.path>` or `<file>:<line>`; `list` prints the ref of each bookmark.

## Commands

| Command | Use |
|---|---|
| `info` | Project root, bookmarks file, branch and counts |
| `list [--file <path>] [--tag <tag>] [--query <text>]` | All bookmarks with their current position |
| `show <ref>` | One bookmark with its note and code |
| `functions <file>` | Functions detected in a file, to pick one to bookmark |
| `add <file>#<Function.path>` or `add <file>:<line>` | Add a bookmark (options: `--label`, `--note`, `--tags a,b`, `--number <1-9>`, `--line`) |
| `set <ref>` | Change one (`--label`, `--note`, `--append-note`, `--tags`, `--add-tag`, `--remove-tag`, `--number <1-9 or 0>`) |
| `remove <ref>` | Remove a bookmark |
| `guide [--tag <tag>] [--file <path>] [--no-code]` | Walkthrough document in Markdown: numbered bookmarks first, with notes and code |

Add `--json` to `info`, `list`, `show`, `functions`, `add`, `set` or `remove` for JSON output.

## How to use it

- Before searching the code for where something happens, run `list` (or `list --query <word>`): the developer may already have bookmarked it with a name and a note. Use `show <ref>` to read the note and the code.
- To explain a flow, start from the numbered bookmarks (`list`, then `show 1`, `show 2`, …) or run `guide`.
- When the developer asks you to mark something, prefer a function bookmark (`add <file>#<Function.path>`); it follows the function by name. Run `functions <file>` if you are not sure of the name. Use a line bookmark (`add <file>:<line>`) for a specific line inside a function.
- Write display names, tags and notes in the developer's language. Notes are Markdown.
- Only add, change or remove bookmarks when the developer asks for it. Do not renumber their bookmarks on your own.
- A bookmark marked `needs checking` lost its original line; tell the developer instead of guessing.
- Never edit `.vscode/function-bookmarks.json` by hand. The editor picks up the changes the CLI makes.
- If the CLI says the bookmarks are stored inside the editor, the developer has to switch the storage to the project file (Function Bookmarks side bar → … → Choose Bookmark Storage for This Workspace) before you can see them.
